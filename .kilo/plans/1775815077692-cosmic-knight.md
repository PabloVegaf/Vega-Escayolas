# Plan: Slider deslizante Antes/Después en Trabajos.astro

## Objetivo
Convertir la línea divisoria estática al 50% entre las imágenes "Antes" y "Después" en un slider interactivo que el usuario puede arrastrar con el ratón (o dedo en móvil) para revelar más o menos de cada imagen.

## Cambios necesarios en `src/components/Trabajos.astro`

### 1. HTML — Añadir handle e etiquetas a cada tarjeta
Dentro de `.tarjeta_imagen`, añadir:
- Un `<div class="slider-handle">` con un icono de flechas izquierda/derecha (SVG inline o caracteres `⟨ ⟩`).
- **Sin etiquetas** "ANTES"/"DESPUÉS" — el usuario las considera obvias e innecesarias.

### 2. CSS — Cambios de estilos
- **Eliminar** el `::after` de `.tarjeta_imagen` (la línea divisoria estática).
- **Eliminar** los `clip-path` fijos de `.imagen_antes` y `.imagen_despues` — se establecerán dinámicamente vía JS con `style` inline (valor por defecto 50%).
- **Añadir** estilos para `.slider-handle`:
  - `position: absolute; top: 0; bottom: 0; width: 4px;`
  - `left: 50%` (por defecto), `z-index: 4`
  - Fondo blanco/claro, `cursor: ew-resize`
  - Pseudo-elemento `::before` con el círculo/tirador centrado verticalmente (icono de flechas)
### 3. JavaScript — Lógica de arrastre
Añadir un `<script>` al final del componente que:
1. Seleccione todos los `.tarjeta_imagen` del componente.
2. Para cada uno, obtenga el handle, la imagen "antes" y la imagen "después".
3. Añada listeners de `mousedown` / `touchstart` al handle.
4. En el evento de inicio, añada listeners `mousemove` / `touchmove` y `mouseup` / `touchend` al `document`.
5. En `move`: calcule la posición X relativa al contenedor (en %), clampeada entre 0% y 100%.
6. Actualice:
   - `clip-path` de `.imagen_antes` → `polygon(0 0, {pos}% 0, {pos}% 100%, 0 100%)`
   - `clip-path` de `.imagen_despues` → `polygon({pos}% 0, 100% 0, 100% 100%, {pos}% 100%)`
   - `left` del `.slider-handle` → `{pos}%`
7. En `end`: elimine los listeners temporales del `document`.
8. Soporte táctil: usar `touch.clientX` de `e.touches[0]` en eventos `touchmove`.

### 4. Accesibilidad
- Añadir `role="slider"` y `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"` al handle.
- Añadir soporte de teclado: `ArrowLeft` / `ArrowRight` mueven el slider ±2%.

## Correcciones TypeScript (para evitar errores en IDE)
El script actual funciona en runtime pero genera errores TypeScript porque:
1. `querySelector` devuelve `Element` genérico, no `HTMLElement`
2. Los eventos tienen tipo `Event` genérico, no `MouseEvent`/`TouchEvent`/`KeyboardEvent`
3. Los parámetros de funciones carecen de tipos explícitos

Cambios necesarios en el `<script>`:
- **Castear elementos**: `as HTMLElement` para acceder a `.style`
- **Tipar eventos**: `(e: MouseEvent)`, `(e: TouchEvent)`, `(e: KeyboardEvent)`
- **Tipar parámetros**: `(x: number)`, `(clientX: number)`
- **Manejar null**: Añadir `if (!element) return;` antes de usar cada elemento

Ejemplo de corrección:
```typescript
const handle = container.querySelector('.slider-handle') as HTMLElement;
const imagenAntes = container.querySelector('.imagen_antes') as HTMLElement;
// etc...

handle.addEventListener('mousedown', (e: MouseEvent) => { ... });
```
